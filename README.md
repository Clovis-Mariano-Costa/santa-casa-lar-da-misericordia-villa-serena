# Santa Casa Lar da Misericórdia Villa Serena

Site institucional estático para a Santa Casa Lar da Misericórdia Villa Serena.

## Escopo

- Projeto social de acolhimento voluntário para pessoas maiores de 18 anos.
- Linguagem pública prudente, sem prometer serviço médico, psicológico, jurídico, hospitalar ou emergencial.
- Vínculo inicial em estruturação com a Associação Social Nações Por Herança - CNPJ 25.228.365/0001-07.
- Link público de IA: `Inteligência Artificial Casa Lar`, apontando para `https://jus9verde.jus9tecnologia.com.br/charlie-echo-social#chat-social`.

## Publicação

O site é composto por HTML, CSS e JavaScript estáticos. Pode ser publicado em GitHub Pages, Cloudflare Pages ou outro serviço de hospedagem estática.

## Cuidado

Não publicar documentos pessoais, RG, CPF, laudos, imagens de documentos, dados de saúde ou histórias individuais sensíveis neste repositório público do site.
